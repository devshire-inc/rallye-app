# src/

- `components/` — componentes React reutilizáveis do design system e da aplicação.
- `hooks/` — hooks customizados (ex.: `usePermission`, Épico 3 — RBAC).
- `pages/` — telas/rotas da aplicação, organizadas por domínio.
- `lib/` — clientes HTTP, utilitários e integração com o contrato do `rallye-api`.
- `styles/` — tokens de design (CSS custom properties) e estilos globais.

Ponto de entrada: `main.tsx` → `App.tsx`.
